PrintGrid is a Django web app for print shops. Upload a sticker design, and see straight away how many stickers fit on one sheet, how much paper is used and how much is wasted, before anything is printed.

It replaces the manual loop of "does it fit? rotate it, change the spacing, recount, work out the waste" with a layout that is calculated in about two seconds.

Features
Interactive preview: your own artwork drawn on the sheet, updating live as you upload or change anything.
Stickers per sheet: the number that fit, with rotation tried automatically for the best fit.
Paper use and waste: percentage used and wasted, with a low / moderate / high waste label.
Multiple designs per sheet: different designs and quantities, optionally kept grouped.
Print settings: 28 paper sizes (A4, A3 and more), custom sheet sizes, orientation, margins, horizontal and vertical spacing, and sheet cost.
Units: millimetres, centimetres or inches, switchable in settings. Calculations always run in mm.
Export: a print-ready PDF (one page per sheet) or a PNG of any sheet.
Saved jobs: every job gets a private link, so it can be reviewed, edited and downloaded later.
Image formats: PNG, JPG, WEBP, TIFF, GIF and BMP, up to 25 MB each.
